Running Performance Prediction Engine

Java · Spring Boot · SMILE · React · Tailwind CSS

The Running Performance Prediction Engine is a personal software project that uses race data and machine learning to forecast athlete performances across multiple running distances. I designed the project around a real problem I understand from competitive running: athletes often want to know how a performance in one event translates to another event, but simple pace calculators do not account for training background, event differences, or performance patterns. The system preprocesses race data, trains regression models, and performs error analysis to improve prediction quality. I used Java and Spring Boot for the backend and SMILE for machine learning functionality, then began building a React and Tailwind CSS companion website to make the tool more accessible. This project demonstrates my interest in combining backend engineering, data modeling, and user-focused design to create software that is both technically meaningful and personally useful.
